# Data Notice

This repository contains compact derived artifacts and protocol scaffolding from
`TAU_CORE_FULL_PACKAGE_001.zip`.

The included stable run is a smoke/protocol run. It is not a real-survey
endpoint validation and must not be cited as a DESI, Planck, Euclid, Rubin, ACT,
or other survey detection.

The package includes:

- source-package manifests and documentation;
- source-package scripts;
- stable smoke-run JSON/CSV outputs;
- derived summary tables and figures generated from those outputs.

Large external survey data products are not redistributed here.  Future real
data runs must document acquisition, licensing, versioning, blind labels,
source-side freeze artifacts, mock provenance, covariance treatment, and
forbidden endpoint fields before validation-grade claims.
